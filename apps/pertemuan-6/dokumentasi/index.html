Catatan Teknis

Ringkasan alat dan konsep yang dipakai pada tugas ini. Setiap topik dapat dibuka dan ditutup; isinya merujuk ke file dan konfigurasi yang benar-benar ada di repository.

Git & GitHub

Istilah. Repository adalah folder proyek beserta seluruh riwayat perubahannya. Commit adalah satu catatan perubahan yang bermakna. Branch adalah jalur pengembangan terpisah. Merge menggabungkan dua branch. Merge conflict terjadi ketika dua branch mengubah bagian yang sama dengan isi berbeda sehingga Git meminta manusia memilih atau menggabungkan hasilnya. Pull Request (PR) adalah usulan penggabungan di GitHub yang dapat ditinjau sebelum di-merge.

Alur yang dipakai di proyek ini.

  • main adalah branch integrasi yang dilindungi: perubahan hanya masuk lewat PR dan check CI build-and-verify harus lulus.
  • feature/pertemuan-6-task-manager memuat pengembangan aplikasi ini dalam commit-commit kecil berformat type: description.
  • docs/pertemuan-6-notes memuat dokumentasi. Kedua branch mengubah baris README yang sama sehingga terjadi merge conflict yang nyata; konflik diselesaikan dengan menggabungkan kedua isi pada commit merge 4ff59f3, lalu PR #5 di-merge dengan merge commit b6ff182.
  • Integrasi akhir ke main dilakukan lewat Pull Request terpisah.

npm

npm mengelola paket (library dan alat) yang dibutuhkan proyek, serta menjalankan scripts yang didefinisikan di package.json.

Script yang tersedia.

  • Workspace Task 6 (apps/pertemuan-6/package.json): dev, check (tsc --noEmit), test (node --test), build (npm run check && vite build), dan preview.
  • Root (package.json): dev:t6, check, build, preview, dan verify:transition.

Dependencies vs devDependencies. dependencies berisi paket yang dipakai aplikasi saat berjalan (@kxrumii/transition-bridge). devDependencies hanya dibutuhkan saat pengembangan dan build (typescript dan vite).

Semantic versioning. Versi berformat MAJOR.MINOR.PATCH. 0.4.0 adalah versi eksak. ^7.0.2 (caret) mengizinkan pembaruan MINOR dan PATCH selama MAJOR tetap 7 (≥7.0.2 dan <8.0.0), sedangkan versi yang pasti terpasang dikunci di package-lock.json.

Workspaces. Root package.json mendaftarkan packages/transition-bridge dan empat aplikasi di apps/ sebagai workspace. Semuanya berbagi satu package-lock.json di root dan dipasang sekaligus dengan npm ci.

TypeScript

Static typing membuat kesalahan seperti salah nama field atau status yang tidak valid terdeteksi sebelum aplikasi dijalankan. Proyek ini memakai mode strict. Contoh dari source:

  • Primitive (string, number, boolean) dan array (readonly Task[]): src/types.ts, src/tasks.ts.
  • Interface Task dan TaskDraft: src/types.ts.
  • Type alias dan union TaskStatus ('belum-selesai' | 'selesai'): src/types.ts; TaskFilter ('all' | 'active' | 'completed'): src/filters.ts.
  • Union terdiskriminasi Result<T, E> (ok: true | false) untuk hasil validasi form: src/validation.ts.
  • Generics updateById<T extends { id: number }>: src/tasks.ts; requireElement<T extends Element>: src/render.ts.
  • Type guard isTask(value: unknown): value is Task untuk memeriksa data dari localStorage: src/storage.ts; isTaskFilter: src/filters.ts.
Vite

Vite adalah build tool sekaligus development server.

  • Development: npm run dev:t6 dari root (menjalankan vite --host 127.0.0.1; alamat tampil di terminal).
  • Build produksi: npm run build --workspace=@kxrumii/pertemuan-6 (pemeriksaan tipe lalu vite build).
  • Konfigurasi (vite.config.ts): base bernilai /tugas/pertemuan-6/ agar aset dimuat dari subpath yang benar, dan hasil build ditulis ke public/tugas/pertemuan-6/ di root repository (folder hasil generate yang tidak di-commit).
  • Masuk ke build Astro: npm run build di root membersihkan output lama, membangun semua aplikasi Vite, lalu menjalankan astro build yang menyalin isi public/ ke dist/tugas/pertemuan-6/.
Environment variables

Nilai konfigurasi yang boleh berbeda antar lingkungan disimpan di file .env dan dibaca lewat import.meta.env.

  • .env adalah file lokal dan tidak di-commit: .gitignore mengabaikan .env dan .env.*, kecuali .env.example.
  • .env.example adalah template yang di-commit dan hanya berisi contoh non-rahasia. Salin menjadi .env untuk pengaturan lokal.
  • Aplikasi ini membaca VITE_APP_NAME dan VITE_APP_VERSION. Nilai yang sedang dipakai halaman ini: nama College Task Manager dan versi 1.0.0. Bila variabel kosong atau tidak ada (misalnya pada CI yang tidak memiliki .env), aplikasi memakai nilai bawaan tersebut sehingga build tetap berjalan.

Peringatan. Variabel berawalan VITE_ disisipkan ke dalam bundle JavaScript dan dapat dibaca siapa pun di browser. Jangan pernah menaruh password, API key, atau secret lain di dalamnya.

Compiler, transpiler & bundler
  • Compiler menerjemahkan kode sumber ke bentuk lain yang dapat dijalankan atau diperiksa, misalnya kode mesin. Pada TypeScript, tsc (compiler TypeScript) memeriksa tipe dan dapat menghasilkan JavaScript.
  • Transpiler menerjemahkan kode sumber ke bahasa lain pada tingkat abstraksi yang setara, misalnya TypeScript menjadi JavaScript dengan menghapus anotasi tipe.
  • Bundler menggabungkan banyak modul dan aset menjadi sedikit file yang efisien dimuat browser.

Di proyek ini: tsc --noEmit (script check) hanya memeriksa tipe dan tidak menghasilkan file JavaScript. Menurut dokumentasi Vite, Vite hanya melakukan transpilation TypeScript dan tidak melakukan type checking, sehingga script build menjalankan npm run check sebelum vite build.

Pada Vite 8, Oxc menjadi bagian toolchain compiler/transformer yang mengubah TypeScript menjadi JavaScript, sedangkan Rolldown adalah bundler-nya. Rolldown bukan pemeriksa tipe; pemeriksa tipe tetap tsc. Sumber: Vite: Features dan Announcing Vite 8.
